# MediaPipe + MOG2 ROI 실행 안내

## 실행 방법

1. Python 3.10 환경을 준비하세요. Conda나 가상환경 사용 여부는 상관없습니다.
2. 아래 세 파일을 같은 폴더에 두세요.
   - `main.py`
   - `squat_analyzer.py`
   - `pose_landmarker_lite.task`
3. 해당 폴더에서 터미널을 열고 실행하세요.

```bash
python -m pip install mediapipe opencv-python
python "main.py"
```

- `python` 명령이 없으면 두 명령 모두 `python3`로 바꿔 실행하세요.
- VS Code 실행 버튼을 쓰면, 패키지를 설치한 Python을 인터프리터로 선택하세요.
- 카메라 권한 요청이 나오면 허용하세요.

## 실행 화면

현재 코드는 창이 2개 열립니다.

| 창 이름 | 내용 |
| --- | --- |
| `MediaPipe Pose Detection` | 관절, 노란 ROI 사각형, 입력 모드, 키 안내를 표시합니다. |
| `MOG2 Foreground Mask` | 배경은 검정, 전경은 흰색으로 표시합니다. |

관절은 첫 번째 창에 표시됩니다.
어깨·엉덩이·무릎·발목은 빨간 점, 나머지는 파란 점입니다.

ROI는 영상에서 분석할 관심 영역입니다.
MOG2 모드에서는 전경을 감싸는 영역을 찾습니다.
그 영역의 원본 영상을 잘라 MediaPipe에 넣습니다.
노란 사각형이 실제 분석 범위입니다.

## 키 조작

영상 창을 클릭하고 영문 소문자로 누르세요.

| 키 | 기능 |
| --- | --- |
| `b` | 학습한 배경을 고정합니다. |
| `m` | 원본 입력과 MOG2 ROI 입력을 전환합니다. `b`를 누른 뒤 사용할 수 있습니다. |
| `r` | 배경을 초기화합니다. 원본 입력으로 돌아가 다시 학습합니다. |
| `q` | 종료합니다. |

## MOG2 ROI 사용 순서

1. 카메라를 고정하고 사람이 없는 배경을 잠시 비추세요.
2. 마스크가 대체로 검게 안정되면 `b`를 누르세요.
3. 화면에 들어와 전신이 보이도록 서세요.
4. `m`을 누르면 MOG2 ROI 모드가 됩니다. 다시 누르면 원본 모드로 돌아갑니다.

노란 사각형에 머리·손·발이 모두 포함되는지 확인하세요.

- `Input: Original`: 원본 전체로 분석 중
- `Input: MOG2 ROI`: MOG2로 찾은 영역으로 분석 중
- `Input: Original (no ROI)`: 유효한 영역이 없어 원본 전체로 분석 중
- `BG: Learning`: 배경 학습 중
- `BG: Fixed`: 배경 고정 완료

배경을 잘못 학습했거나 카메라를 움직였다면 `r`을 누르세요.
화면에서 빠진 뒤, 마스크가 안정되면 다시 `b`를 누르세요.
